# Literasi Digital Mahasiswa Baru

## Deskripsi Proyek
Repository ini digunakan untuk mengelola persiapan kegiatan Literasi Digital bagi mahasiswa baru Universitas Indonesia. Seluruh dokumentasi, pembagian tugas, dan perkembangan kegiatan dicatat melalui GitHub agar mudah dipantau oleh seluruh anggota kelompok.

## Tujuan Kegiatan

- Meningkatkan literasi digital mahasiswa baru.
- Mengenalkan etika bermedia sosial.
- Mengembangkan kemampuan verifikasi informasi.
- Mendorong penggunaan teknologi digital secara bertanggung jawab.
